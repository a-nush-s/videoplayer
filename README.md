# videoplayer
A python-based video player that selects a random video you have included in a folder, plays a random 5 seconds of it, and then randomly picks another video to repeat. You can pause/play, skip, mute, and change the video duration in the built-in gui.
To add videos to the rotation, please make a folder called "videos" (all lowercase, plural) and add your videos. This folder should be next to videoplayer.py. This program will look for all video extensions (mp4, mov, avi, mkv, webm). 
You will need to install Pillow and ffpyplayer to run this program. 
You can run this with "python videoplayer.py". The app will open in a window titled "Video Player".
